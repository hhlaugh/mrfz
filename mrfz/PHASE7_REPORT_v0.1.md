## 3. 机器人的信息边界（如实实现）

- 动作候选：仅 `enumerateLegalActions(state, bot)`（每个候选都经过引擎 `reduceGameAction` 验证），最终执行仍走 `controller.dispatch → reduceGameAction`，不存在绕过路径。
- 读取的状态：自己的手牌 ID、双方在场单位（公开棋盘：HP/SP/护盾/状态/位置）、双方基本分与费用、设施与待处理选择、卡牌定义（公开数据）。
- **不读取**：对手手牌内容、牌库顺序、`random_state`。重复状态哈希对此有专门测试（打乱对手手牌顺序哈希不变）。
- 评分只做启发式估计，不执行引擎结算；退款/伤害等真实数值全部由引擎计算。

## 4. 策略实现（普通难度启发式评分，取最高分 + 微小抖动）

| 动作 | 评分要点 |
|---|---|
| 部署 | 单位价值（HP/ATK/浮空/嘲讽/技能）− 费用惩罚；**补空路 +1.0 / 受威胁要道 +0.9 / 空路推进 +1.1**；敌方基本分 ≤8 时空路斩杀加权，己方 ≤8 时防守加权；近战前位/远程后位偏好；`on_deploy` 产费加权（桃金娘） |
| 伤害战术 | 有效伤害 ×0.55 + 目标威胁加权 − 费用；**可击杀时 + 目标价值 ×0.55**（"有击杀机会时考虑伤害卡"） |
| 控制战术（眩晕/冻结/捕网） | 控制价值 1.5/1.1 + 高威胁目标（ATK≥3）额外加权；捕网由引擎合法性天然只允许浮空目标（"考虑浮空"） |
| 治疗（急救包） | 只按实际可回复量计分 |
| 主动技能 | 有效伤害 + 击杀奖励 − SP 机会成本；**有效伤害 <2 且不可击杀时拒绝发动**（"SP 足够且有价值目标时发动"） |
| 普通撤离 | **仅当单位将被击杀（同路最大敌方攻击 ≥ HP+护盾）时为正分**，否则 −1.5（"只在确有收益时"） |
| 快速撤离 | 消耗手牌基准成本 −0.8；救命/解控（眩晕冻结冻结减速）才为正分，≤0.5 直接拒绝 |
| 回合开始支援选择 | 优先 SP 缺口大的前排单位；无可用目标时跳过 |
| 结束行动阶段 | 基线 0 分——无正收益动作时自然胜出 |

## 5. 重复状态检测、watchdog 与日志

- **重复状态检测**：机器人维护最近 32 个决策局面的哈希（含回合、费用、基本分、己方手牌、公开棋盘全量、待处理选择）；同一局面第 3 次出现时，仅允许"推进型动作"（部署/出牌/处理选择/结束阶段），禁止撤离与技能空转，并计入 telemetry。
- **AI 决策 watchdog（仅 AI 内部安全措施，不是玩家规则限制）**：① 单局决策数上限（默认 3000）超限后强制保守动作；② 单次决策评分动作数上限（800）与时间预算（50ms）截断评分并记录。引擎侧的触发队列深度 32 安全阀不受影响。
- **日志**：`log` 回调注入（UI 传入 console，模拟默认静默）；每次决策记录回合、模式、所选动作、分数与考察数量；watchdog/重复检测/回退均记录并计入 telemetry（`decisions / watchdogStops / repetitionStops / fallbacks`）。

## 6. 自动模拟统计（A/B 牌组、座次互换，120 局常驻测试）

`src/ai/simulation.test.ts`：seed 1–60，每 seed 跑"常规座次 + A/B 互换座次"各一局（共 120 局），机器人全部动作经引擎验证。

| 指标 | 数值 |
|---|---|
| 完成局数 | 120 / 120（全部正常终局，无平局保护上限触发） |
| 总耗时 | ≈1.7 秒（约 14ms/局） |
| A 牌组胜率 / B 牌组胜率 / 平局 | 72.5% / 27.5% / 0 |
| 平均回合数 / 最长回合 | 16.7 / 34 |
| 平均动作数 / 部署次数 | 59.3 / 20.4 每局 |
| 战术卡 | 7.54 每局 |
| **撤离率** | 普通 11.07 + 快速 0.68 ≈ **11.8 次每局** |
| **技能频率** | 0.13 次每局 |
| watchdog 触发 / 重复状态触发 | **0 / 0** |

> 说明：以上为**普通难度启发式 bot 互打**的观察值，用于验证策略可运行、对局可正常终局，**不构成卡牌平衡结论**（平衡评估见 `RULE_AUDIT_v0.7.md` §2，需更强的 bot 或真人数据）。A 牌组显著占优与其低成本部署循环对随机-ish 防守的克制一致，留待后续难度/策略迭代观察。

## 8. 已知事项

1. 技能频率偏低（0.13/局）：史都华德需 3 SP 且要求同路目标，普通难度评分对其发动条件较保守；冻结/眩晕等控制卡使用正常。属策略调参空间，不是缺陷。
2. 快速撤离使用率低（0.68/局）：评分门槛"确有收益"刻意保守，符合要求原文。
3. 机器人决策日志在 UI 模式走 `console.info`（浏览器控制台可见）；如需界面内展示可在阶段 8+ 一并规划。
4. 机器人动作被引擎拒绝时（理论上不应发生）会回退到首个合法动作并计入 telemetry——模拟 120 局 + 单元测试中均未出现。
