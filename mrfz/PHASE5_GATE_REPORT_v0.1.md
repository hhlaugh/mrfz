## 6. 测试覆盖清单（52 项，按域分组）

**数据加载与校验（5）**：16 卡 + 2 套 20 张牌组加载且不改源记录；快速撤离两项豁免显式；白名单/引用/牌组规模/同名≤2 校验；重复卡 ID 拒绝；数据池与 v0.7 字段契约对齐后无告警。

**引擎基础与回合流程（13）**：双 20 张牌组、起手 5 张、20 基本分/0 费用；同 seed 洗牌发牌复现且不突变输入；等量换牌、暂存洗回、不触发疲劳；换牌原子拒绝（他方/重复/重复换牌）；同名≤2 牌组校验；双方换牌完成后才定先手且随机源可注入；疲劳 1+2+3 独立计数；手牌上限弃牌不疲劳；疲劳至 0 判负；双方同时 0 判平；+3 费用、上限 10、未用保留；四阶段严格交替、回合开始抽 1；越权/未实现动作拒绝且状态不变。

**部署、撤离、CD、支援与原子性（17）**：近战/远程/浮空后位部署限制；费用不足与占位拒绝不部分扣费不移动手牌；同名不同实例独立槽位与生命周期；普通撤离（己方控制 + 己方半区 + `floor(paid×0.5)` 退款 + 战斗重置 + 生命周期/CD 保留）；无豁免的强制撤离不可绕过控制或半区；快速撤离对对方控制单位原子拒绝；快速撤离后立即再部署并重复触发费用收益；支援设施目标选择先于自然 SP、全冻结面板不消耗触发上限；设施≤2、装备≤1、宿主撤离装备进弃牌堆；撤离当回合结束不递减 CD、跳过下一个己方行动阶段后可再部署。

**战斗、目标算法、SP 与控制状态（13）**：仅行动方攻击、左→中→右、前位→后位；死亡后重选目标；仅眩晕防守时打基地；嘲讽 → 合法地面拦截前后位 → 远程优先浮空；近战可打临时落地浮空、不可打原生浮空；减速只影响下一次攻击、冻结使嘲讽失效；护盾先于 HP、基地归零立即终局；反应技能先扣 SP（不能用本次受击 SP 倒付）；受击 SP 在攻击结算后获得；击杀 SP 归属；冻结封自然 SP 而眩晕不封；grounded 独立于控制两回合到期；眩晕/冻结战术经校验动作生效；主动技能原子扣 SP、禁用眩晕/冻结单位。

**触发队列（2）**：优先级排序与稳定 tie-break；递归再入触发链在深度 32 处切断。

**确定性模拟与状态性质（2）**：同 seed + 同动作流 → 完全相同终局；200 局逐动作不变量校验（闸门另补 1000 局）。
